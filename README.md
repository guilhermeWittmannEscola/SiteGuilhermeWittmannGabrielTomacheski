📖 Sobre o projeto

O Pegada Hídrica é um site educativo desenvolvido com o objetivo de conscientizar sobre o consumo de água e incentivar hábitos mais sustentáveis.

O projeto apresenta informações sobre o conceito de pegada hídrica, comparações do consumo de água em diferentes produtos, curiosidades, estatísticas e uma calculadora interativa que estima o consumo semanal de água do usuário com base em seus hábitos.

Além de informar, o site proporciona uma experiência dinâmica por meio de animações, desafios, quiz e diversos recursos interativos.
